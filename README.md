# こえのかけら

声や文字で残した小さな出来事を、時刻ごとのタイムラインとして眺められる個人用の記録帳です。紙をちぎって重ねたような画面と、空・草花の切り絵風装飾で、日常の断片をやさしく残せる体験を目指しています。

TanStack Start と React で構築しています。

## できること

- マイクを使った日本語の音声入力
- テキストを直接入力しての記録
- 日付・時刻ごとのタイムライン表示
- 記録内容と時刻の編集、個別削除
- 全記録のテキストコピー
- 全記録の削除
- ブラウザ内への自動保存

## はじめかた

### 必要なもの

- Node.js 20 以降
- pnpm 10 以降

### インストールと起動

```bash
pnpm install
pnpm dev
```

起動後、[http://localhost:3000](http://localhost:3000) を開きます。

## 使い方

1. 画面下部の丸いマイクボタンを押します。
2. 記録したい時刻と内容を入力します。
3. マイクボタンを押すと、対応ブラウザでは音声入力を開始できます。もう一度押すと停止します。
4. 「はりつける」を押すと、内容がタイムラインに追加されます。
5. 記録の右側に表示される「なおす」「はがす」から、編集または削除できます。

## 音声入力について

音声入力にはブラウザの Web Speech API を利用しています。利用できるかどうかはブラウザとその設定に依存します。

- 初回利用時は、ブラウザからマイク利用の許可を求められます。
- 音声入力に非対応のブラウザでも、テキストでの記録は利用できます。
- マイクが利用できない場合は、ブラウザのサイト設定でマイク権限を確認してください。

## データの保存場所と注意点

記録はサーバーへ送信せず、利用しているブラウザのローカルストレージに保存されます。

- 同じブラウザ・同じ端末で開いたときだけ記録を引き継げます。
- シークレットモードや、サイトデータを削除した場合は記録が失われることがあります。
- 端末間の同期、アカウント、バックアップ機能は現時点ではありません。
- 「文字でコピー」を使うと、記録をプレーンテキストとして外部に控えられます。

## 技術構成

- [TanStack Start](https://tanstack.com/start) — SSR対応のアプリケーション基盤
- [TanStack Router](https://tanstack.com/router) — ファイルベースのルーティング
- React 19
- Vite
- TypeScript

## 主なファイル

```text
src/
├── routes/
│   ├── __root.tsx   # HTMLドキュメント、メタデータ、共通レイアウト
│   └── index.tsx    # 記録帳の画面と操作
├── router.tsx       # TanStack Routerの設定
├── routeTree.gen.ts # 自動生成されるルート定義
├── styles.css       # 紙の質感・切り絵装飾を含むスタイル
└── vite-env.d.ts    # Viteの型定義
```

`src/routeTree.gen.ts` はルーティング用プラグインが生成するファイルです。手で編集せず、ルートファイルの追加・変更後に開発サーバーまたはビルドを実行して更新してください。
